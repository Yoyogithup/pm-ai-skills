# 财务规划助手 Skill

## 概述

这个 skill 提供完整的个人财务规划能力，包括首次规划、期中调整和小调整三种场景。

## 快速开始

**主入口文件**：[skill.md](skill.md)

当用户提出财务规划相关需求时，skill 会自动：
1. 识别用户意图（首次规划/期中调整/小调整/知识咨询）
2. 调用对应的工作流
3. 按需读取知识库和规则文件
4. 生成结构化的分析报告和操作清单

## 触发条件

skill 会在以下情况下被调用：
- 用户说"帮我做财务规划"
- 用户说"复盘一下我的资产"
- 用户提供资产数据要求分析
- 用户咨询投资基础知识（如"什么是定投"）

## 使用方式

### 方式1：自动触发（推荐）
直接向我提出需求，skill 会自动识别场景：
- "帮我规划一下资产配置" → 首次规划
- "帮我复盘一下现在的持仓" → 期中调整
- "我买了XXX，帮我更新一下" → 小调整
- "什么是定投？" → 知识咨询

### 方式2：手动调用
```bash
/wealth-planning
```
然后说明你的具体需求。

## 核心能力

### 1. 智能诊断
- 资产配置失衡检测
- 重复持仓识别
- 亏损资产预警
- 风险暴露分析

### 2. 方案设计
- 基于风险偏好的配置建议
- 多方案对比（激进/稳健/保守）
- 收益风险测算
- 分批投入计划

### 3. 执行指导
- 定投设置清单
- 逢低加仓触发点
- 止损止盈提醒
- 操作步骤拆解

### 4. 持续监控
- 定期复盘提醒
- 配置漂移预警
- 弱势资产淘汰
- 再平衡建议

# 重复持仓检查规则

## 1. 重复度定义

### 1.1 完全重复（100%）
**定义**：跟踪完全相同的指数或资产

**示例**：
- 天弘标普500C + 摩根标普500
- 华夏恒生ETF + 易方达恒生ETF

**处理**：必须合并，保留其中一只
- 优先保留：费率更低、规模更大、流动性更好的

---

### 1.2 高度重复（60-90%）
**定义**：持仓重叠度超过60%

**示例**：
- 华夏5G通信 + 中欧数字经济（重叠60%）
  - 5G包含：中兴通讯、中国移动等
  - 数字经济包含：通信设备 + 互联网软件
  - 重叠：通信设备股

- 广发纳斯达100 + 银华海外数字经济（重叠60%）
  - 纳指：苹果、微软、谷歌、特斯拉等
  - 数字经济：阿里、腾讯、拼多多 + 部分美股科技
  - 重叠：科技股属性

**处理**：强烈建议合并
- 如果都要保留，主力仓位放一只，另一只小仓位（<20%）
- 例：纳指¥30,000 + 数字经济¥10,000

---

### 1.3 中度重复（40-60%）
**定义**：持仓重叠度40-60%

**示例**：
- 易方达科创50 + 华夏半导体（重叠40%）
  - 科创50包含：半导体、新能源、生物医药、高端制造
  - 半导体：仅芯片产业链
  - 重叠：科创板的半导体股

- 易方达科创50 + 华夏机器人（重叠50%）
  - 科创50包含：自动化设备、机器人相关
  - 机器人：工业机器人、服务机器人
  - 重叠：智能制造

**处理**：可以保留，但需注意
- 如果总仓位有限（如<¥100,000），建议合并
- 如果总仓位充足，可以保留，但单只不要太小

---

### 1.4 低度重复（20-40%）
**定义**：持仓重叠度20-40%

**示例**：
- 易方达科创50 + 天弘光伏（重叠30%）
  - 科创50包含：部分光伏企业
  - 光伏：仅光伏产业链
  - 重叠：科创板的光伏股

- 华夏沪深300 + 华夏半导体（重叠30%）
  - 沪深300包含：部分科技股
  - 半导体：仅芯片股
  - 重叠：沪深300中的芯片公司

**处理**：可以保留，属于合理配置
- 宽基 + 行业主题 是常见组合
- 例：沪深300（底仓）+ 半导体（卫星）

---

### 1.5 独立配置（<20%）
**定义**：持仓重叠度<20%

**示例**：
- 天弘光伏 + 华夏半导体（重叠10%）
  - 光伏：硅料、电池、逆变器
  - 半导体：芯片设计、制造
  - 几乎独立

- 东证红利低波动 + 广发纳斯达100（重叠0%）
  - 红利：A股高股息蓝筹
  - 纳指：美股科技成长
  - 完全独立

**处理**：鼓励保留，分散风险

---

## 2. 重复检查流程

### 2.1 自动检查清单

当用户提供资产数据时，执行以下检查：

#### 步骤1：识别同类基金
- [ ] 美股基金：标普500系列、纳指系列、美股科技系列
- [ ] 红利基金：A股红利、港股红利
- [ ] 科技基金：半导体、5G、数字经济、科创50、机器人
- [ ] 宽基：沪深300、中证500、恒生等
- [ ] 债基：混债、短债、中长债
- [ ] 黄金：黄金ETF、黄金基金

#### 步骤2：计算重叠度
使用以下矩阵参考：

**美股**：
- 天弘标普500C + 摩根标普500 = 100%
- 广发纳指 + 银华数字经济 = 60%

**A股红利**：
- 东证红利 + 易方达红利 = 70%
- 东证红利 + 易方达恒生红利 = 10%

**科技**：
- 华夏5G + 中欧数字经济 = 60%
- 易方达科创50 + 华夏半导体 = 40%
- 易方达科创50 + 华夏5G = 50%
- 易方达科创50 + 中欧数字经济 = 50%
- 易方达科创50 + 华夏机器人 = 50%
- 华夏半导体 + 华夏机器人 = 40%
- 天弘光伏 + 其他科技 = 10-30%

#### 步骤3：标注问题
生成重复持仓清单：
```
重复持仓报告
1. 【严重】天弘标普500C + 摩根标普500（100%重复）
   → 建议：保留摩根标普，清仓天弘
   
2. 【较严重】华夏5G + 中欧数字经济（60%重复）
   → 建议：合并为科创50
   
3. 【中度】科创50 + 半导体（40%重复）
   → 建议：可保留，但注意仓位分配
```

- "我不确定" → 提供观察期，3个月后再决定

## 3. 去重原则

### 3.1 优先保留规则

**规则1：宽>窄**
- 保留覆盖面广的基金
- 例：科创50（覆盖多行业） > 5G通信（单一行业）

**规则2：大>小**
- 保留规模大、流动性好的基金
- 例：易方达红利ETF（规模大） > 小规模红利基金

**规则3：低费率>高费率**
- 例：ETF（费率0.5%） > 主动基金（费率1.5%）

**规则4：强>弱**
- 保留历史表现更好的基金
- 例：博时稳健增利（收益4.03%） > 中银国企债（收益0.85%）

**规则5：用户偏好**
- 如果用户明确喜欢某只基金，可以保留
- 但需提醒风险和重复问题

---

### 3.2 合并策略

**策略1：全部卖出A，买入B**
- 适用：A完全重复B，且B更优
- 例：卖出天弘标普500C，买入摩根标普500

**策略2：主次配置**
- 适用：用户坚持保留两只
- 例：纳指¥30,000（主） + 数字经济¥10,000（次）

**策略3：停止定投A**
- 适用：不想卖出A（可能有成本优势），但不再增配
- 例：保留现有5G持仓，停止定投，新增资金投入科创50

---

## 4. 特殊情况处理

### 4.1 用户坚持保留重复基金
**场景**：用户有特殊理由（如看好某个主题、分批建仓）

**处理**：
1. 充分解释重复的弊端
2. 尊重用户选择
3. 建议主次分配（7:3或8:2）
4. 设置观察期（3-6个月后复查）

**记录**：
- 在记忆中记录用户偏好
- 例："用户坚持保留5G通信，原因：看好5G-A升级周期"

---

### 4.2 重复但收益差距大
**场景**：
- 华夏5G：+19.59%
- 中欧数字经济：+20.61%
- 虽然重复60%，但收益都很好

**处理**：
- 短期可以保留（享受收益）
- 但提醒：牛市都涨，熊市都跌
- 建议：达到止盈目标后合并

---

### 4.3 低仓位重复
**场景**：
- 两只基金重复60%
- 但单只仓位都<¥1,000

**处理**：
- 直接合并，不纠结
- 小仓位保留多只意义不大

---

## 5. 去重后的验证

完成去重后，重新检查：

### 5.1 配置结构检查
- [ ] 每个模块有明确定位
- [ ] 模块之间重叠度<40%
- [ ] 单只基金仓位>¥10,000（除观察仓外）

### 5.2 覆盖度检查
- [ ] 美股：有标普500或纳指
- [ ] A股：有宽基或科技
- [ ] 债基：有混债或短债
- [ ] 黄金：有黄金基金（可选）
- [ ] 红利：有红利策略（可选）

### 5.3 风险分散检查
- [ ] 不同地域：A股、美股、港股
- [ ] 不同资产：股票、债券、黄金
- [ ] 不同风格：成长、价值、红利

## 7. 常见问题

### Q1：为什么要去重？
- 分散变成重复，没有降低风险
- 单只仓位太小，涨跌对总收益影响小
- 管理成本高，需要盯多只基金

### Q2：保留多少只基金合适？
- 总资产<50万：8-12只
- 总资产50-100万：12-15只
- 总资产>100万：15-20只
- 原则：单只仓位>¥10,000

### Q3：如何判断两只基金是否重复？
- 看基金名称（跟踪相同指数）
- 看前十大持仓（重叠度>60%）
- 看行业分布（高度相似）

### Q4：去重后会不会错过机会？
- 不会，宽基金已覆盖主题
- 例：科创50 包含 5G、半导体、新能源
- 没必要单独买5G基金

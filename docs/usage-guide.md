# 📘 使用指南

本文档介绍如何有效使用 PM AI Skills。

## 基本使用流程

### 1. 选择合适的技能

根据你的工作场景选择对应分类的技能：

- **产品工作** → 需要写 PRD、做分析
- **日常生活** → 个人时间管理、学习笔记
- **项目管理** → 项目规划、会议管理
- **好玩的 Skill** → 创意工具、可视化

### 2. 阅读技能说明

每个技能都有独立的 README，包含：
- 功能介绍
- 使用方法
- 输出示例
- 使用技巧

**建议**：第一次使用前仔细阅读说明

### 3. 调用技能

在 QoderWork 中输入技能名称：

```
/prd-doc-writer
```

### 4. 按提示操作

大多数技能会有交互式引导，按照提示逐步完成。

### 5. 优化输出

AI 生成的内容可以根据实际情况调整和优化。

## 最佳实践

### ✅ DO - 推荐做法

1. **准备充分** - 使用前整理好素材和思路
2. **分步完成** - 复杂任务分多次迭代
3. **灵活调整** - 根据实际情况修改输出
4. **保存模板** - 常用的输出可以保存为模板
5. **持续改进** - 在使用中不断优化提示

### ❌ DON'T - 避免做法

1. **过度依赖** - AI 是辅助工具，不能完全替代思考
2. **照搬不改** - 生成的内容需要结合实际调整
3. **忽略检查** - 输出内容要仔细检查，确保准确性
4. **一次完成** - 不要期望一次就生成完美结果

## 常见场景示例

### 场景 1：快速起草 PRD

```
目标：为一个新功能快速起草 PRD

步骤：
1. /prd-doc-writer
2. 输入功能背景和目标
3. 描述用户场景
4. 列出核心功能点
5. 生成初稿
6. 根据评审意见迭代
```

### 场景 2：绘制流程图

```
目标：绘制用户注册流程

步骤：
1. /drawing
2. 描述流程："用户注册流程，包含邮箱验证和手机验证"
3. AI 生成流程图代码
4. 根据实际情况调整细节
5. 导出或嵌入文档
```

## 技巧与窍门

### 提高输出质量

1. **详细描述** - 提供越详细的上下文，输出越准确
2. **举例说明** - 提供参考案例让 AI 理解你的期望
3. **分步引导** - 大任务拆分成小步骤
4. **及时反馈** - 输出不满意时明确指出问题

### 提升效率

1. **快捷调用** - 熟悉常用技能的调用方式
2. **模板复用** - 保存常用的输出模板
3. **批量处理** - 相似任务批量完成
4. **键盘快捷键** - 使用快捷键提升操作速度

## 故障排查

### 技能无响应
- 检查技能名称是否正确
- 重启 QoderWork
- 查看技能文件是否完整

### 输出不符合预期
- 提供更详细的描述
- 明确指出期望的格式和内容
- 尝试分步骤引导

### 遇到错误提示
- 查看错误信息
- 检查输入格式
- 查看技能的 README 说明

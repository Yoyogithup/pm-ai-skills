# 📚 使用示例

这里收集了各种技能的实际使用案例和示例输出。

## 📁 目录结构

```
examples/
├── product-work/           # 产品工作技能示例
├── daily-life/            # 日常生活技能示例
├── project-management/    # 项目管理技能示例
└── fun-skills/            # 好玩技能示例
```

## 🎯 如何使用示例

1. **学习参考** - 查看示例了解技能的实际效果
2. **模板复用** - 将示例作为模板进行修改
3. **对比优化** - 对比你的输出和示例，找到优化空间

## 📝 示例内容

每个示例通常包含：
- 使用场景描述
- 输入内容
- 输出结果
- 使用心得

## 🤝 贡献示例

欢迎分享你的使用案例！

提交方式：
1. Fork 本仓库
2. 在对应分类下添加你的示例
3. 提交 PR

示例格式建议：
```markdown
# 示例：[场景名称]

## 场景描述
简要描述使用场景...

## 输入
提供的输入内容...

## 输出
生成的结果...

## 心得体会
使用过程中的经验和技巧...
```

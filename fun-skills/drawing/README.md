# 绘图助手

> 快速创作图表和可视化内容

## 📝 功能介绍

绘图助手帮助你快速创建各种类型的图表和可视化内容，无需手动绘制，AI 自动生成。

## ✨ 主要特性

- ✅ **多种图表类型** - 流程图、架构图、思维导图等
- ✅ **自动布局** - 智能排版，美观清晰
- ✅ **快速迭代** - 轻松修改和优化
- ✅ **多格式导出** - 支持多种导出格式

## 🎨 支持的图表类型

- 📊 流程图（Flowchart）
- 🏗️ 架构图（Architecture Diagram）
- 🧠 思维导图（Mind Map）
- 📈 数据可视化图表
- 🔄 时序图（Sequence Diagram）
- 更多类型持续添加中...

## 🚀 使用方法

### 前置要求
- 已安装 Claude Code 或支持 AI Skills 的环境

### 安装步骤
1. 将 `skill.md` 文件复制到你的 skills 目录
2. 按照 Claude Code 的 skill 安装流程进行配置

### 使用示例

```
/drawing

描述你需要的图表：
"画一个用户注册流程图，包括邮箱验证和手机验证两种方式"
```

## 📚 输出示例

根据不同图表类型，输出相应的可视化内容（Mermaid、PlantUML 等格式）

## 💡 使用技巧

1. **清晰描述** - 越详细的描述，生成的图表越准确
2. **分步绘制** - 复杂图表可以分模块逐步完成
3. **迭代优化** - 根据初稿反馈进行调整
4. **保存模板** - 常用图表可以保存为模板复用

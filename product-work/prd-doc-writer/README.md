# PRD 文档生成助手

> 智能化 PRD 文档生成，让需求撰写更高效

## 📝 功能介绍

这是一个基于 AI 的 PRD 文档生成助手，通过结构化引导帮助产品经理快速产出规范的产品需求文档。

## ✨ 主要特性

- ✅ **结构化引导** - 分步骤引导，确保 PRD 完整性
- ✅ **最佳实践模板** - 内置行业最佳实践
- ✅ **智能补充** - 自动补充遗漏内容
- ✅ **多轮迭代** - 支持持续优化完善

## 🚀 使用方法

### 前置要求
- 已安装 Claude Code 或支持 AI Skills 的环境

### 安装步骤
1. 将 `skill.md` 文件复制到你的 skills 目录
2. 按照 Claude Code 的 skill 安装流程进行配置

### 使用示例

```
/prd-doc-writer

然后按照提示逐步完成：
1. 产品背景与目标
2. 用户分析与场景
3. 功能需求详细说明
4. 非功能需求
5. 验收标准
```

## 📚 输出示例

生成的 PRD 文档包含：
- 产品概述
- 用户分析
- 功能需求清单
- 详细功能说明
- 验收标准
- 项目计划

## 💡 使用技巧

1. **准备充分** - 使用前准备好背景资料和需求素材
2. **分步完成** - 不要急于一次性完成，可以分多次迭代
3. **灵活调整** - AI 生成的内容可以根据实际情况调整
4. **团队评审** - 生成后与团队评审，确保需求准确

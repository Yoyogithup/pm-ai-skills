# Demo 演示视频自动录制

> 自动化录制高清产品演示视频，提升产品交付效率

## 📝 功能介绍

这是一个基于 Playwright 的 Demo 演示视频自动录制工具，可根据 HTML Demo 和 PRD 文档自动生成录屏脚本，录制 1080P 高清视频，并上传到钉钉文档整理归档。

## ✨ 主要特性

- ✅ **智能场景规划** - 分析 PRD 自动拆解录制场景
- ✅ **自动化录制** - 基于 Playwright 的浏览器自动化
- ✅ **1080P 高清** - 支持 1080P 60fps 高质量视频
- ✅ **格式转换** - 自动转换为 MP4 格式（H.264）
- ✅ **文档整合** - 自动上传到钉钉文档并整理

## 🚀 使用方法

### 前置要求
- 已安装 QoderWork 或支持 AI Skills 的环境
- 已安装 Node.js 和 FFmpeg

### 安装步骤
1. 将 `SKILL.md` 文件复制到你的 skills 目录（`~/.qoderwork/skills/`）
2. 重命名为 `record-demo.md`

### 使用示例

```bash
/record-demo /path/to/demo.html /path/to/prd.md
```

完整流程：
1. Claude 分析 Demo 和 PRD
2. 规划录制场景（3-6个）
3. **与你确认场景规划**（必需）
4. 生成 Playwright 自动化脚本
5. 执行录制（1080P）
6. 转换为 MP4 格式
7. 上传到钉钉文档

### FFmpeg 转换
```bash
ffmpeg -i input.webm \
  -c:v libx264 \      # H.264编码
  -preset slow \       # 更好的压缩
  -crf 18 \           # 高画质
  output.mp4
```

## 💡 使用技巧

1. **场景规划** - 每个场景 1-2 分钟，3-6 个场景为宜
2. **质量优先** - 使用 1080P 分辨率，CRF 18 高画质
3. **错误处理** - 遇到超时立即修复，不等批量录完
4. **批量操作** - 视频转换可并行执行提高效率

## ⏱️ 预计耗时

| 阶段 | 耗时 | 说明 |
|-----|------|------|
| 分析规划 | 5-10分钟 | 理解需求、规划场景 |
| 生成脚本 | 10-15分钟 | 编写 Playwright 代码 |
| 安装依赖 | 2-5分钟 | 首次需下载浏览器 |
| 执行录制 | 视场景而定 | 每个场景 1-2 分钟 |
| 格式转换 | 2-5分钟 | 批量转换为 MP4 |
| 上传整理 | 3-5分钟 | 上传并创建文档 |

**总计**：30-60 分钟（vs 手动录制 2-3 小时）

# Demo 演示视频自动录制 Skill

根据提供的 HTML Demo 和 PRD 文档，自动生成 Playwright 录屏脚本，录制高清演示视频，并整理上传到钉钉文档。

## 📋 功能概述

本 skill 可以完成以下完整流程：

1. **分析 PRD** - 理解产品需求和交互流程
2. **规划场景** - 根据 PRD 拆解录制场景
3. **生成脚本** - 创建 Playwright 自动化录屏脚本
4. **执行录制** - 自动操作浏览器并录制视频
5. **格式转换** - 转换为高清 MP4 格式
6. **上传整理** - 上传到钉钉文档并添加说明

## 🎯 使用方式

```bash
/record-demo [demo路径] [PRD路径]
```

**参数说明**：
- `demo路径`: HTML Demo 文件的路径（必填）
- `PRD路径`: PRD 文档路径（可选，如果未提供则通过询问获取）

**示例**：
```bash
/record-demo /path/to/demo.html /path/to/prd.md
/record-demo /path/to/demo.html
```

## 📥 输入要求

### 必需输入
- **Demo HTML 文件**: 可交互的前端 Demo
  - 必须是完整的 HTML 文件
  - 包含所有必要的 CSS/JS
  - 可以在浏览器中正常运行

### 可选输入
- **PRD 文档**: 产品需求文档
  - 包含功能说明和交互流程
  - 如果未提供，会要求用户描述需要录制的场景

### 额外参数（通过交互收集）
- **视频分辨率**: 默认 1080P (1920x1080)
- **钉钉文档位置**: 默认存放到用户配置的默认知识库文件夹

## 🔧 执行流程

### 第一步：分析与规划（5-10分钟）

1. **读取 Demo 文件**
   - 解析 HTML 结构
   - 识别交互元素（按钮、表单、链接等）
   - 理解页面流程和状态变化

2. **分析 PRD（如果提供）**
   - 提取核心功能点
   - 识别关键交互路径
   - 确定需要演示的场景

3. **规划录制场景**
   - 将功能拆解为独立场景（建议 3-6 个）
   - 每个场景时长控制在 1-2 分钟
   - 确定每个场景的操作步骤

4. **🔴 与用户确认场景（必需）**
   - 向用户展示规划的场景列表
   - 包含每个场景的：
     - 场景名称
     - 预计时长
     - 主要操作步骤
     - 关键演示点
   - 等待用户确认或修改
   - **只有用户确认后才开始下一步**

### 第二步：生成自动化脚本（10-15分钟）

1. **创建项目结构**
   ```
   auto-record/
   ├── package.json
   ├── record.js
   ├── README.md
   ├── 快速开始.md
   └── videos/
   ```

2. **配置 Playwright**
   - 设置视频录制参数（分辨率、帧率）
   - 配置视口大小
   - 设置操作延迟（slowMo）

3. **编写场景函数**
   - 为每个场景创建独立函数
   - 实现自动化操作（点击、输入、等待）
   - 添加错误处理和防御性检查
   - **重要**: 使用 `page.isVisible()` 检查元素存在后再操作

4. **关键技术要点**
   ```javascript
   // ✅ 正确：先检查元素是否存在
   const hasButton = await page.isVisible('.some-button');
   if (hasButton) {
     await clickAndWait(page, '.some-button', 1000);
   }
   
   // ❌ 错误：直接点击可能超时
   await clickAndWait(page, '.some-button', 1000);
   ```

5. **配置示例**
   ```javascript
   const CONFIG = {
     viewport: { width: 1920, height: 1080 },  // 1080P
     slowMo: 500,                               // 操作延迟
     videoSize: { width: 1920, height: 1080 }, // 录制分辨率
     videoFps: 60,                              // 帧率
   };
   ```

### 第三步：执行录制（录制时长依场景而定）

1. **安装依赖**
   ```bash
   npm install
   ```
   - 首次安装会下载 Playwright 浏览器（~200MB）
   - 预计耗时 2-5 分钟

2. **测试运行**
   ```bash
   npm run test
   ```
   - 快速验证脚本是否正常工作
   - 只打开浏览器 10 秒

3. **录制各个场景**
   ```bash
   npm run record:scene1
   npm run record:scene2
   npm run record:scene3
   # ... 更多场景
   ```
   
4. **问题处理**
   - 如果出现超时错误，检查元素选择器
   - 添加 `page.isVisible()` 防御性检查
   - 增加等待时间或 slowMo 延迟
   - 重新录制问题场景

### 第四步：格式转换（2-5分钟）

1. **批量转换为 MP4**
   ```bash
   cd videos
   for file in *.webm; do
     ffmpeg -i "$file" -c:v libx264 -preset slow -crf 18 "${file%.webm}.mp4"
   done
   ```

2. **转换参数说明**
   - `crf 18`: 高画质（18 推荐，越小质量越高）
   - `preset slow`: 更好的压缩效率
   - `libx264`: H.264 编码，兼容性最好

### 第五步：上传到钉钉文档（3-5分钟）

1. **创建汇总文档**
   - 在默认知识库文件夹创建文档
   - 标题格式：`[项目名] Demo 录屏视频集合`
   - 包含视频列表、时长、大小等信息

2. **上传视频文件**
   - 使用 `get_file_upload_info` 获取上传凭证
   - 通过 curl 上传到 OSS
   - 使用 `commit_uploaded_file` 提交文件
   - **注意**: 上传时 Content-Type 必须设置为空

3. **更新文档内容**
   - 添加视频链接（钉钉文档格式）
   - 包含每个场景的详细说明
   - 添加技术参数（分辨率、时长等）

## ⚠️ 注意事项

### 录制质量优化
1. **分辨率设置**
   - 移动端 Demo: 375x812 (iPhone 12 Pro)
   - 桌面端 Demo: 1920x1080 (1080P)
   - 可根据实际需求调整

2. **操作延迟**
   - 默认 500ms 适合大部分场景
   - 复杂动画可增加到 800-1000ms
   - 简单操作可减少到 300ms

3. **场景时长**
   - 单个场景建议 1-2 分钟
   - 避免超过 3 分钟（文件过大）
   - 复杂流程拆分为多个场景

### 常见问题处理

1. **元素找不到/超时**
   - 添加 `page.isVisible()` 检查
   - 增加等待时间
   - 检查选择器是否正确
   - 使用更通用的选择器

2. **视频质量不佳**
   - 提高分辨率 (1080P → 4K)
   - 降低 CRF 值 (18 → 15)
   - 提高帧率 (30fps → 60fps)

3. **上传失败**
   - 确保 Content-Type 设置为空
   - 检查网络连接
   - 重新获取上传凭证（可能过期）

4. **Demo 状态随机**
   - 使用 Demo 控制面板重置状态
   - 通过 `page.evaluate()` 强制设置状态
   - 添加更多等待时间确保状态稳定

# 调研问卷生成器

> 基于调研主题生成专业调查问卷，并进行信度、效度、完成率等多维度质量检查

## 📝 功能介绍

一个专业的调研问卷生成技能，支持从调研主题自动生成完整问卷，并提供全面的质量评估。基于 KANO 模型、MECE 原则等专业方法论设计。

## ✨ 主要特性

- ✅ **智能题目生成** - 基于调研主题自动规划问卷结构和题目
- ✅ **专业方法论** - 内置 KANO 模型、MECE 原则、认知负荷理论
- ✅ **多维度质量检查** - 信度、效度、完成率、移动端适配性评分
- ✅ **移动端优先** - 题目设计考虑手机填写体验
- ✅ **完整参考资料** - 附带题型设计、量表设计等参考文档

## 🚀 使用方法

### 快速使用

告诉 AI 你的调研主题，例如：
- "帮我设计一份用户满意度调研问卷"
- "我想做一个产品功能需求验证的调查"
- "设计一份关于 XX 功能的用户使用习惯问卷"

### 工作流程

1. **确认调研目标** - 明确调研对象、目的、预期产出
2. **规划问卷结构** - 确定维度和题目数量
3. **生成问卷题目** - 包含题型、选项、逻辑跳转
4. **质量检查** - 多维度评分和优化建议
5. **输出最终问卷** - 可直接导入问卷平台使用

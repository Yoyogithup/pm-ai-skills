# 调研问卷生成器

基于调研主题生成专业、可量化的调查问卷，并提供全面的质量检查。

## 触发场景

当用户有以下需求时自动应用此 skill：

### 场景 A：生成新问卷
- "帮我设计一份关于 XXX 的问卷"
- "生成调研问卷"
- "设计调查表/反馈表"

### 场景 B：检查/优化现有问卷
- "检查这份问卷的质量"
- "优化问卷设计"
- "评估这份问卷"
- "帮我看看这份问卷有没有问题"
- "这份问卷设计得怎么样"

## 工作流程

## 工作流程

### Phase 1: 需求澄清（必须执行）

在生成问卷前，必须通过提问确认以下信息：

1. **调研主题**：具体想了解什么？
2. **目标受众**：谁来填写？（如：职场人士、大学生、消费者）
3. **调研目的**：用于什么决策？（如：产品优化、市场分析、学术研究）
4. **发放渠道**：线上/线下？预计回收多少份？
5. **特殊要求**：是否有必须包含的问题或避开的敏感话题？

### Phase 2: 问卷结构设计与确认（必须执行）

**⚠️ 重要：在生成完整问卷前，必须先输出问卷结构并获得用户确认。**

#### 步骤 1：输出问卷结构草案

基于 Phase 1 确认的需求，输出以下结构框架：

```markdown
## 【调研主题】问卷结构草案

### 一、整体框架
- **标题**：【建议标题】
- **预计题数**：X 题
- **预计完成时间**：X 分钟
- **结构类型**：【标准结构/漏斗结构/矩阵结构/自定义结构】

### 二、结构模块设计

| 模块 | 题号范围 | 题目数量 | 设计目的 | 题型分布 |
|------|----------|----------|----------|----------|
| 【筛选/热身】 | Q1-Q3 | 3题 | 过滤无效样本，建立信任 | 单选/多选 |
| 【维度A】 | Q4-Q7 | 4题 | 测量基本型需求 | 单选+量表 |
| 【维度B】 | Q8-Q12 | 5题 | 测量期望型需求 | 量表+排序 |
| 【维度C】 | Q13-Q15 | 3题 | 测量兴奋型需求 | 单选+开放 |
| 【信度检验】 | Q16-Q17 | 2题 | 相似问题+测谎题 | 单选 |
| 【人口统计】 | Q18-Q20 | 3题 | 样本特征分析 | 单选 |

### 三、逻辑流程图
【用文本或 ASCII 图展示问卷逻辑】

例如：
开始 → 筛选题(Q1) → 不符合条件→结束
            ↓
      符合条件 → 热身题(Q2-Q3) → 主体问题(Q4-Q17) → 人口统计(Q18-Q20) → 结束

### 四、关键设计说明

1. **KANO 覆盖**：
   - 基本型需求：通过【维度A】的 X 个问题测量
   - 期望型需求：通过【维度B】的 X 个问题测量
   - 兴奋型需求：通过【维度C】的 X 个问题测量

2. **信度保障**：
   - 相似问题：Q【X】与 Q【Y】用于一致性检验
   - 测谎题：Q【Z】

3. **特殊设计**：
   - 【如有逻辑跳转、随机化等，在此说明】

---

**请确认以上结构是否符合您的预期？**
- 如有调整需求，请告诉我：
- 确认无误后，我将生成完整问卷。
```

#### 步骤 2：等待用户确认

**必须获得用户明确确认后才能进入 Phase 3。**

用户可能的反馈类型：
- ✅ "确认，生成完整问卷" → 进入 Phase 3
- 📝 "调整：增加 XX 维度" → 修改结构后再次确认
- 📝 "调整：删除第 X 题" → 修改结构后再次确认
- 📝 "调整：改变顺序" → 修改结构后再次确认

### Phase 3: 完整问卷生成

基于 Phase 2 确认的问卷结构，生成完整问卷。

#### 问卷结构类型参考

根据调研目标，可选择以下结构类型：

**1. 标准结构（通用型）**
```
筛选/热身 → 主体问题（按维度分组） → 人口统计 → 结束语
```
- 适用：大多数调研场景
- 特点：逻辑清晰，易于分析

**2. 漏斗结构（由宽到窄）**
```
广泛行为 → 具体场景 → 深度态度 → 决策因素
```
- 适用：探索性研究、用户画像
- 特点：层层深入，减少认知负荷

**3. 矩阵结构（多维度对比）**
```
维度A问题组 → 维度B问题组 → 维度C问题组 → 交叉验证题
```
- 适用：产品功能评估、竞品对比
- 特点：结构化程度高，便于对比分析

**4. 情景结构（故事线）**
```
背景设定 → 场景A问题 → 场景B问题 → 综合决策
```
- 适用：用户体验研究、购买决策
- 特点：沉浸感强，回答更真实

#### 标准模块说明

**1. 标题**
- 简洁明了，一眼明白调研目的
- 格式：【主题】+【调查/调研】

**2. 导语**
- 调研目的和意义
- 填写说明（时间、题型提示）
- 隐私声明

**3. 筛选/热身问题（2-3题）**
- 第1题：筛选目标人群（如"您是否使用过X？"）
- 第2-3题：浅显易答，建立信任

**4. 主体问题（按逻辑梯度排列）**
- 按维度分组，每组3-5题
- 从浅入深，从行为到态度

**5. 人口统计信息（3-5题）**
- 年龄、性别、职业、收入等
- 放在最后，避免敏感感

**6. 结束语**
- 感谢语
- 可选：留下联系方式参与后续访谈

#### 2. 设计原则（2024-2025 最新标准）

| 原则 | 具体要求 |
|------|----------|
| **KANO 模型覆盖** | 包含基本型需求、期望型需求、兴奋型需求的问题 |
| **信度保障** | 设计 1-2 组相似但表述不同的问题（用于一致性检验），加入注意力检查题 |
| **效度保障** | 表面效度（通俗易懂无歧义）+ 内容效度（紧扣调研目标）+ 结构效度 |
| **认知负荷控制** | 每页不超过 5 题，使用渐进式披露，减少记忆负担 |
| **移动优先** | 适配手机端，触控友好，避免复杂交互 |
| **完成率保障** | 问题均可回答、不涉及隐私敏感信息、逻辑顺畅、控制问卷疲劳 |

#### 3. 问题设计规范（最新标准）

**题量控制（基于 2024 研究）**：
- **最佳题数**：10-15 题（完成率最高）
- **上限**：不超过 20 题（超过后放弃率显著上升）
- **完成时间**：5-8 分钟（移动端）/ 8-12 分钟（PC端）

**认知负荷管理**：
- **每页题数**：不超过 5 题（减少滚动和认知负担）
- **选项数量**：单选题不超过 7 个选项（工作记忆限制）
- **问题长度**：每题不超过 20 字，避免长句
- **渐进披露**：复杂问题拆分为简单子问题

**题型配比**：
- 封闭式问题占 80% 以上
- 开放式问题不超过 2 个（且放在最后）
- 量表题占主体问题的 40-60%

**语言规范**：
- 使用受访者熟悉的语言，避免专业术语
- 问题表述中立，不暗示特定答案
- 每个问题只围绕一个目的，不能兼问
- 提供"不知道""无所谓""其他"等选项确保穷尽

**移动优化**：
- 按钮大小适配触控（最小 44×44px）
- 避免使用滑块题（在手机上操作困难）
- 优先使用单选按钮而非下拉菜单

#### 4. 量表题设计指南

**李克特量表选择标准**：

| 点数 | 适用场景 | 优点 | 缺点 |
|------|----------|------|------|
| **5 点** | 一般态度测量、快速调研 | 简单明了，适合手机端 | 区分度有限 |
| **7 点** | 需要更精细区分、学术研究 | 数据更接近正态分布 | 认知负担略高 |
| **4/6 点** | 强制表态、避免中庸 | 防止趋中偏差 | 可能引入偏差 |
| **11 点** | NPS 等推荐度测量 | 接近连续变量 | 选项过多 |

**量表设计原则**：
- 保持方向一致（避免正负混合）
- 标注两端含义（如 1=非常不满意，5=非常满意）
- 提供"不适用"选项（当受访者无法回答时）
- 奇数量表提供中立选项，偶数量表强制表态

#### 5. 注意力检查与数据质量控制

**注意力检查题（Attention Check）**：
- **类型 1 - 指令题**："请选择'非常同意'"
- **类型 2 - 陷阱题**：插入不存在的选项（如"GenAI Pro"）
- **类型 3 - 一致性题**：相似问题检验回答一致性
- **放置位置**：问卷前 1/3、中 1/3、后 1/3 各 1 题

**响应质量指标**：
- **完成时间**：过短（<1 分钟）或过长（>30 分钟）需审查
- **直线作答**：连续 5 题以上选择同一选项
- **矛盾回答**：逻辑上不可能的回答组合
- **开放题质量**：无意义回答（如"aaaa"）

#### 6. 题型选择指南

| 题型 | 适用场景 | 移动端友好度 | 示例 |
|------|----------|--------------|------|
| 单选题 | 互斥选项、明确分类 | ⭐⭐⭐⭐⭐ | "您的年龄段是？" |
| 多选题 | 可多选、非互斥 | ⭐⭐⭐⭐ | "您使用过哪些 AI 工具？" |
| 量表题 | 态度、频率、满意度 | ⭐⭐⭐⭐⭐ | "满意度（1-5分）" |
| 排序题 | 优先级判断 | ⭐⭐⭐ | "请排序以下因素" |
| NPS 题 | 推荐意愿 | ⭐⭐⭐⭐⭐ | "您向朋友推荐的可能性（0-10）" |
| 开放式 | 深度洞察 | ⭐⭐ | "您还有什么建议？" |
| 滑块题 | 连续变量 | ⭐⭐ | 避免在移动端使用 |

#### 7. 选项合理性检查标准（MECE 原则）

**MECE 原则**：Mutually Exclusive（互斥）+ Collectively Exhaustive（穷尽）

**A. 互斥性检查（Mutually Exclusive）**

单选题选项之间必须完全互斥，不能存在重叠。

| 问题类型 | 错误示例（有重叠） | 正确示例（互斥） |
|----------|-------------------|------------------|
| **年龄段** | 18-25岁 / 25-35岁 | 18-25岁 / 26-35岁 |
| **收入** | 5000-8000元 / 8000-10000元 | 5000-8000元 / 8001-10000元 |
| **频率** | 经常 / 有时 / 偶尔 | 每天 / 每周几次 / 每月几次 |

**检查方法**：
- 对于数值类选项，检查边界值是否重叠
- 对于分类类选项，检查类别定义是否清晰不重叠
- 对于频率类选项，使用明确的时间范围而非模糊词汇

**B. 穷尽性检查（Collectively Exhaustive）**

选项必须覆盖所有可能的回答情况。

| 场景 | 必须包含的选项 | 说明 |
|------|----------------|------|
| **所有单选题** | "其他（请注明）" | 覆盖未预见到的情况 |
| **知识类问题** | "不知道" / "不了解" | 允许无知识者作答 |
| **态度类问题** | "无所谓" / "中立" | 允许中立态度 |
| **不适用场景** | "不适用" / "没有经历过" | 允许跳过相关问题 |
| **敏感问题** | "不愿透露" | 保护隐私 |

**检查方法**：
- 列出所有可能的回答情况
- 检查是否有遗漏的场景
- 确保"其他"选项可以覆盖边缘情况

**C. 选项平衡性检查**

| 检查项 | 标准 | 错误示例 | 正确示例 |
|--------|------|----------|----------|
| **正负平衡** | 正负选项数量对称 | 3个正面 / 1个负面 | 2个正面 / 2个负面 |
| **程度递进** | 选项按程度排列 | 非常同意 / 同意 / 不同意 / 非常不同意 | 非常同意 / 同意 / 中立 / 不同意 / 非常不同意 |
| **表述一致** | 语法结构相似 | 产品质量好 / 价格不贵 / 会推荐 | 产品质量满意 / 价格满意 / 推荐意愿强 |

**D. 选项数量检查**

| 题型 | 最佳数量 | 最大数量 | 说明 |
|------|----------|----------|------|
| **单选题** | 4-5 个 | ≤ 7 个 | 超过 7 个考虑使用多选或分级 |
| **多选题** | 5-7 个 | ≤ 10 个 | 超过 10 个考虑分类或搜索 |
| **排序题** | 3-5 个 | ≤ 7 个 | 超过 7 个排序困难 |
| **量表题** | 5 或 7 点 | - | 根据精度需求选择 |

**E. 选项顺序**

| 策略 | 适用场景 | 示例 |
|------|----------|------|
| **逻辑顺序** | 时间、程度、大小 | 18岁以下 → 18-25岁 → 26-35岁... |
| **随机化** | 避免首因效应 | 品牌偏好、产品特性 |
| **固定顺序** | 有明确社会规范 | 非常满意 → 满意 → 一般... |

**F. 选项表述规范**

| 原则 | 错误示例 | 正确示例 |
|------|----------|----------|
| **简洁** | 我每周都会去健身房锻炼 | 每周都去 |
| **具体** | 经常 / 偶尔 | 每天 / 每周几次 |
| **互斥** | 18-25岁 / 25-35岁 | 18-25岁 / 26-35岁 |
| **全面** | 满意 / 不满意 | 非常满意 / 满意 / 一般 / 不满意 / 非常不满意 |
| **中性** | 优秀的产品 / 差劲的产品 | 非常满意 / 非常不满意 |

### Phase 4: 质量检查（2024-2025 标准）

生成问卷后，必须进行以下维度的自检：

#### 检查清单

```
□ 信度检查（Reliability）
  □ 是否有 1-2 组相似问题用于一致性检验？
  □ 是否包含 2-3 道注意力检查题（前/中/后各 1 题）？
  □ 问题表述是否稳定可靠（无模糊词汇）？
  □ 量表题是否有足够题数计算 Cronbach's α（每个维度 ≥3 题）？

□ 效度检查（Validity）
  □ 表面效度：题目是否通俗易懂、无歧义、无专业术语？
  □ 内容效度：是否覆盖调研目标的所有维度？
  □ 结构效度：问题分组是否符合理论框架？
  □ 共同方法偏差：是否通过设计控制（如匿名、随机化）？

□ 认知负荷检查（Cognitive Load）
  □ 每页题数是否 ≤5 题？
  □ 问题长度是否 ≤20 字？
  □ 选项数量是否 ≤7 个？
  □ 是否使用渐进式披露（复杂问题拆分）？
  □ 是否有进度指示器？

□ 移动优化检查（Mobile-First）
  □ 是否避免使用滑块题？
  □ 是否优先使用单选按钮而非下拉菜单？
  □ 触控目标是否足够大（≥44px）？
  □ 是否适配小屏幕阅读？

□ 选项合理性检查（Mutually Exclusive & Exhaustive - MECE 原则）
  □ 单选题选项是否互斥（无重叠）？
  □ 选项是否穷尽（覆盖所有可能情况）？
  □ 是否包含"其他（请注明）"选项？
  □ 是否包含"不知道/不确定"选项（适用时）？
  □ 选项表述是否平衡（正负选项对称）？
  □ 选项顺序是否合理（逻辑顺序或随机化）？
  □ 选项数量是否适中（单选 ≤7，多选 ≤10）？

□ 设计规范检查
  □ 标题是否简洁明了（≤15 字）？
  □ 导语是否包含目的、说明、隐私声明、预计时间？
  □ 问题梯度是否合理（浅→深）？
  □ 封闭式问题占比是否 ≥80%？
  □ 开放式问题是否 ≤2 个且放在最后？
  □ 每个问题是否单一目的（无双重问题）？
  □ 是否存在引导性问题？
  □ 问题是否可量化（避免"经常""很少"等模糊词）？
  □ 总题数是否在 10-15 题（最佳）或 ≤20 题（上限）？
  □ 预计完成时间是否在 5-8 分钟（移动端）？

□ 用户体验检查
  □ 是否涉及隐私敏感问题（姓名、电话、身份证号）？
  □ 逻辑顺序是否顺畅？
  □ 是否有问卷疲劳控制（题量、时间）？
  □ 结束语是否包含感谢和后续说明？
```

#### 评分标准（2024-2025 版）

| 维度 | 权重 | 评分细则 | 得分 |
|------|------|----------|------|
| **信度** | 20% | 相似问题(5%) + 注意力检查题(8%) + 表述稳定(5%) + 量表题数充足(2%) | /20 |
| **效度** | 20% | 表面效度(5%) + 内容效度(10%) + 结构效度(5%) | /20 |
| **认知负荷** | 15% | 每页题数(4%) + 问题长度(4%) + 选项数量(4%) + 渐进披露(3%) | /15 |
| **移动优化** | 10% | 避免滑块(3%) + 触控友好(4%) + 屏幕适配(3%) | /10 |
| **选项合理性** | 15% | 互斥性(5%) + 穷尽性(5%) + 平衡性(3%) + 数量适中(2%) | /15 |
| **设计规范** | 10% | 结构完整(4%) + 题型合理(3%) + 题量控制(3%) | /10 |
| **用户体验** | 10% | 无隐私问题(5%) + 逻辑顺畅(5%) | /10 |

**评分等级**：
- **90-100 分**：优秀，可直接使用
- **80-89 分**：良好，建议微调
- **70-79 分**：合格，需优化后使用
- **< 70 分**：不合格，需重新设计

#### 预调查建议（Pretest）

**预调查样本量**：
- 最小：30 人（可进行基础统计分析）
- 推荐：50-100 人（可检验信效度）
- 公式：预试题目最多分量表题目数的 3-5 倍

**预调查检验内容**：
1. **信度检验**：Cronbach's α ≥ 0.7 为可接受，≥ 0.8 为良好
2. **效度检验**：探索性因子分析（EFA）检验结构效度
3. **共同方法偏差**：Harman 单因子检验（第一因子解释率 < 40%）
4. **题目分析**：题目-总分相关系数 ≥ 0.3

**数据清洗标准**：
- 完成时间 < 1 分钟 或 > 30 分钟 → 剔除
- 注意力检查题错误 ≥ 2 题 → 剔除
- 直线作答（连续 5 题相同选项）→ 剔除
- 开放题无意义回答 → 剔除

## 模式 2：检查现有问卷（专项流程）

## 示例

### 示例 1：职场人士 AI 使用情况调研（生成模式）

**输入**：
- 主题：职场人士使用 AI 的情况
- 受众：一二线城市白领
- 目的：了解 AI 工具的普及度和使用场景
- 渠道：线上问卷星

**输出要点**：
- 包含 AI 工具认知度、使用频率、使用场景、满意度等维度
- 设计相似问题："您每天使用 AI 工具的时长？" 与 "AI 工具在您工作中的占比？"
- 测谎题："您是否使用过以下不存在的 AI 工具？"
- 总题数控制在 18 题

### 示例 2：检查现有问卷（检查模式）

**输入**：用户提供的一份问卷

**输出**：质量检查报告，包含：
- 总体评分和等级
- 逐题检查结果（特别是选项互斥性和穷尽性）
- 详细的优化建议（高/中/低优先级）
- 可选：修改后的问卷

## 注意事项

1. **隐私保护**：绝不询问姓名、电话、身份证号等敏感信息
2. **文化适配**：根据受众调整语言风格（学术/口语化）
3. **逻辑跳转**：复杂问卷可设计跳转逻辑，但需清晰标注
4. **预测试建议**：建议正式发放前找 3-5 人预测试

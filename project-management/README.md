# 📊 工作项目管理技能

提升项目管理和团队协作效率的 AI 技能。

## 🎯 技能目标

这些技能专注于项目管理场景：
- 项目规划与跟进
- 团队协作优化
- 会议管理
- 风险识别与管理
- 进度追踪报告

## 🚧 即将推出

以下技能正在开发或计划中：

- **项目启动助手** - 快速生成项目启动文档
- **会议纪要整理** - 自动化会议纪要生成
- **风险识别助手** - 项目风险识别和应对方案
- **周报生成器** - 智能生成项目周报
- **里程碑规划** - 项目里程碑和时间线规划

## 💡 使用建议

1. **标准化流程** - 使用技能建立标准化的项目管理流程
2. **团队共识** - 与团队成员分享，建立共同的工作方式
3. **持续改进** - 根据项目实际情况调整技能参数

# 📊 工作项目管理技能

提升项目管理和团队协作效率的 AI 技能。

## 🎯 技能目标

这些技能专注于项目管理场景：
- 项目规划与跟进
- 团队协作优化
- 会议管理
- 风险识别与管理
- 进度追踪报告

## 📚 可用技能

### [performance-review](./performance-review/)
通用绩效自评助手，自动适配不同评估体系（OKR/KPI/价值观/能力素质模型），基于工作文档生成结构化自评总结。

**功能特点：**
- ✅ 对话式收集公司评估背景
- ✅ 三套输出模板适配不同公司
- ✅ 量化优先的撰写规范
- ✅ 中英文双语支持

**适用场景：**
- 年度/半年/季度绩效自评
- 工作总结撰写
- 晋升述职材料准备

[查看详情 →](./performance-review/)

1. **标准化流程** - 使用技能建立标准化的项目管理流程
2. **团队共识** - 与团队成员分享，建立共同的工作方式
3. **持续改进** - 根据项目实际情况调整技能参数

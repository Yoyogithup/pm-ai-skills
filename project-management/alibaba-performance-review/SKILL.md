# 阿里绩效自评生成器

## 工作流程

### 第一步：收集工作文档

请用户提供以下材料：

1. **OKR文档** - 用于梳理年度工作目标
2. **详细工作文档** - 用于提取具体工作内容和成果

如果用户未提供文档，提示用户上传或粘贴相关内容。

### 第二步：分析工作内容

阅读用户提供的文档，提取以下信息：

- 年度核心目标（从OKR中提取）
- 各项目/模块的关键交付物
- 可量化的成果数据
- 遇到的挑战及解决方案
- 协作与影响力

### 第三步：生成绩效自评

按照以下结构撰写，字数控制在1000-1500字：

```markdown
## 年度业绩评估

### 工作模块一：模块名称
- 工作内容一：工作内容描述，核心交付物，带来了价值
- 工作内容二：工作内容描述，核心交付物，带来了价值

### 工作模块二：模块名称
- 工作内容一：工作内容描述，核心交付物，带来了价值
- 工作内容二：工作内容描述，核心交付物，带来了价值

## 年度价值观评估：A

- 客户第一、员工第二、股东第三：工作内容/事件 + 符合价值观的描述
- 因为信任，所以简单：工作内容/事件 + 符合价值观的描述
- 唯一不变的是变化：工作内容/事件 + 符合价值观的描述
- 今天最好的表现是明天最低的要求：工作内容/事件 + 符合价值观的描述
- 此时此刻，非我莫属：工作内容/事件 + 符合价值观的描述
- 认真生活，快乐工作：工作内容/事件 + 符合价值观的描述
```

## 撰写规范

### 年度业绩评估要求

1. **工作模块划分**：按项目或业务模块组织，每个模块下列出具体工作内容
   
   - 工作内容描述：做了什么
   - 核心交付物：产出了什么
   - 带来的价值：可量化的业务价值

2. **量化原则**：尽可能包含数字，如：
   
   - 用户数、GMV、DAU等业务指标
   - 功能上线数量、迭代次数
   - 效率提升百分比
   - 覆盖站点/地区数量

### 年度价值观评估要求

1. **总体评分**：在标题后标注 A/B/C 档
2. **逐条撰写**：按六大价值观顺序，每条包含：
   - 具体工作内容或事件
   - 如何体现该价值观的描述

阿里六大价值观：

- 客户第一、员工第二、股东第三
- 因为信任，所以简单
- 唯一不变的是变化
- 今天最好的表现是明天最低的要求
- 此时此刻，非我莫属
- 认真生活，快乐工作

## 输出检查清单

- [ ] 按工作模块组织业绩内容
- [ ] 每个工作内容包含描述、交付物、价值三部分
- [ ] 价值观评估给出总体评分（A/B/C）
- [ ] 六大价值观逐条撰写，每条都有具体事件支撑
- [ ] 总字数在1000-1500字范围内，业绩评估至少800字，价值观评估至少300字
- [ ] 包含具体数据和量化指标

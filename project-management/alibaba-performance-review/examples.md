# 阿里绩效自评示例

## 示例一：产品经理年度绩效自评

```markdown
## 年度业绩评估

### 工作模块一：Goofish独客核心功能建设
- 完成APP发布、导购、消息等基础功能建设，实现用户体验闭环，支撑APP快速迭代验证海外市场可能性
- 完成鱼塘主页建设、活动及评论功能，拉动用户互动与活跃，用户日均互动次数提升120%
- 搭建交易正逆向及纠纷处理机制，实现线上交易功能闭环，交易成功率达到95%

### 工作模块二：APP商品&用户冷启动
- 通过与淘宝海外、闲鱼国内合作，完成Goofish淘宝小程序及闲鱼端内投放，淘宝小程序贡献所在国家/地区28%的注册用户，48%的发布商品数
- 闲鱼投放后建立3个种子用户群（500+），与第一批用户成功建立沟通渠道，用户反馈响应时效提升至24小时内

### 工作模块三：业务卡点问题解决
- 组织完成海外用户调研，收集有效反馈200+条，输出产品优化建议15项
- 推动APP多语言能力建设，完成全球16个站点多语言适配
- 解决全球应用市场上线卡点及合规问题，保障APP在全球16个站点顺利铺开

## 年度价值观评估：A

- 客户第一、员工第二、股东第三：深入海外用户社群，每周与用户直接沟通，基于用户反馈优化产品功能5项，用户NPS提升15分
- 因为信任，所以简单：与淘宝海外、闲鱼国内团队建立高效协作机制，通过坦诚沟通快速推进合作项目，减少不必要的流程审批
- 唯一不变的是变化：面对海外市场的不确定性，快速调整产品策略，从0到1搭建海外C2C交易体系
- 今天最好的表现是明天最低的要求：持续优化产品体验，在APP上线后不断迭代，月均发布版本数从2个提升至4个
- 此时此刻，非我莫属：主动承担应用市场上线卡点、APP冷启动、海外用户调研等非职责范围内任务，推动业务突破
- 认真生活，快乐工作：积极参与公司公益活动，本年度公益时为12.0小时，组织团队团建活动6次
```

## 示例二：研发工程师年度绩效自评

```markdown

- 支撑日均千万级订单处理，大促期间系统平稳运行，零故障

### 工作模块二：性能优化专项
- 通过缓存策略优化、数据库索引重构、异步化处理等手段，将核心接口平均响应时间从800ms降至150ms
- 用户体验显著提升，页面加载速度提升60%，投诉率下降40%
- 编写性能优化最佳实践文档，在团队内分享推广

### 工作模块三：技术能力建设
- 搭建团队CI/CD流水线，代码发布效率提升50%，发布失败率降低至1%以下

## 年度价值观评估：A

- 客户第一、员工第二、股东第三：主动收集业务方反馈，针对高频痛点问题发起专项优化，业务方满意度从75%提升至92%

- 此时此刻，非我莫属：在系统大促期间主动承担值班任务，连续3个周末驻守公司保障系统稳定
- 认真生活，快乐工作：组织团队技术沙龙8次，带动团队学习氛围，团队技术氛围评分部门第一
```

## 撰写技巧

### 1. 业绩描述公式
```
工作内容：做了什么 + 产出了什么 + 带来什么价值（数据）
```

### 2. 价值观描述公式
```
价值观：具体事件 + 如何体现该价值观
```

### 3. 常用数据指标参考
- 用户类：DAU、MAU、留存率、转化率、NPS
- 业务类：GMV、订单量、客单价、复购率
- 效率类：响应时间、吞吐量、发布频率、故障率
- 成本类：获客成本、运营成本、人效提升

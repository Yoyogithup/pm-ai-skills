# 通用绩效自评助手

> 自动适配不同评估体系，基于工作文档生成结构化绩效自评总结

## 📝 功能介绍

一个通用的绩效自评文档生成器，通过对话收集公司背景和评估要求，结合用户的工作文档，输出结构化、可量化的绩效自评。适用于任何公司的绩效考核场景。

## ✨ 主要特性

- ✅ **对话式背景收集** - 先了解公司评估体系，再定制输出
- ✅ **三套输出模板** - 业绩+价值观 / 业绩+能力素质 / 纯业绩回顾
- ✅ **量化优先** - 自动提炼和强调数据指标
- ✅ **中英文双语** - 支持中文和英文两种输出风格
- ✅ **灵活适配** - OKR/KPI/价值观/能力模型均可覆盖

## 🚀 使用方法

### 快速使用

告诉 AI 你要写绩效自评，例如：
- "帮我写绩效文档"
- "帮我生成年度工作总结"
- "Help me write a self-review"

### 工作流程

1. **了解评估背景** - 考核周期、评估维度、公司价值观/行为准则
2. **收集工作文档** - OKR/KPI 文档、项目总结、周报月报
3. **分析工作内容** - 提取目标、交付物、量化成果
4. **生成绩效自评** - 按对应模板输出结构化文档

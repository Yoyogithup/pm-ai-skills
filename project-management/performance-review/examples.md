# 绩效自评示例

## 示例一：互联网产品经理 — 业绩 + 价值观模式（中文）

> 背景：某电商平台，年度考核，公司有核心价值观体系

```markdown
## 业绩回顾

### 模块一：XX业务核心功能建设
- 完成 APP 发布、导购、消息等基础功能建设，实现用户体验闭环，支撑 APP 快速迭代验证新市场可能性
- 完成社区主页建设、活动及评论功能，拉动用户互动与活跃，用户日均互动次数提升 X%
- 搭建交易正逆向及纠纷处理机制，实现线上交易功能闭环，交易成功率达到 X%

### 模块二：用户冷启动与增长
- 通过跨产品合作完成小程序及端内投放，小程序贡献所在地区 X% 的注册用户、X% 的发布商品数
- 建立 X 个种子用户群（X+ 人），与第一批用户成功建立沟通渠道，用户反馈响应时效提升至 X 小时内

### 模块三：业务卡点攻坚
- 组织完成用户调研，收集有效反馈 X+ 条，输出产品优化建议 X 项
- 推动多语言能力建设，完成 X 个站点多语言适配
- 解决应用市场上线卡点及合规问题，保障 APP 在 X 个站点顺利铺开

## 价值观评估：[自评等级]

- 客户导向：深入用户社群，每周与用户直接沟通，基于反馈优化产品功能 X 项，用户 NPS 提升 X 分
- 开放透明：与多个兄弟团队建立高效协作机制，通过坦诚沟通快速推进合作项目，减少不必要的流程审批
- 拥抱变化：面对新市场的不确定性，快速调整产品策略，从 0 到 1 搭建 XX 交易体系
- 追求卓越：持续优化产品体验，APP 上线后不断迭代，月均发布版本数从 X 个提升至 X 个
- 主人翁精神：主动承担应用市场上线卡点、冷启动、用户调研等跨职责任务，推动业务突破
```

## 示例三：运营经理 — 纯业绩回顾模式（中文）

> 背景：某中型公司，季度 OKR 回顾，无价值观评估要求

```markdown
## 工作总结

### 核心目标达成情况

| 目标 | 预期结果 | 实际结果 | 完成度 |
|------|---------|---------|--------|
| 用户增长 | DAU X万 | DAU X万 | X% |
| 内容生态 | 月活创作者 X | 月活创作者 X | X% |
| 大促 GMV | 同比增长 X% | 同比增长 X% | X% |

### 重点工作回顾

#### 用户增长突破
- 通过精细化运营策略，实现 DAU 从 X 万增长至 X 万，增长率 X%，超额完成季度目标
- 搭建社群运营体系，社群渠道带来新增用户 X 万，获客成本较付费投放降低 X%
- 优化用户激活流程，新用户 7 日留存率从 X% 提升至 X%

#### 内容生态建设
- 搭建 UGC 内容激励体系，月活跃创作者从 X 人增长至 X 人
- 优化内容分发策略，优质内容产出量提升 X%，用户停留时长增加 X%
- 建立创作者分层运营机制，头部创作者月均产出提升 X%

#### 大促活动操盘
- 主导 X 次大促活动，GMV 同比增长 X%，超额完成业绩目标
- 创新活动玩法，活动参与率从 X% 提升至 X%，裂变玩法被评为公司标杆案例
- 协调产品、技术、设计等 X+ 团队，保障活动顺利上线

### 挑战与成长
- 面对平台算法调整导致的流量波动，X 周内快速调整内容策略，恢复并超越此前流量水平
- 首次独立操盘大促活动，从方案设计到资源协调积累了全链路操盘经验
```

## 撰写技巧

### 业绩描述公式
```
做了什么（行为）+ 产出了什么（交付物）+ 带来什么价值（量化数据）
```

### 价值观/能力描述公式
```
具体事件（何时何地做了什么）+ 如何体现该维度（行为与结果的关联）
```

### 常用量化指标参考

- **用户类**：DAU、MAU、留存率、转化率、NPS、CSAT
- **业务类**：GMV、订单量、客单价、复购率、营收、市场份额
- **效率类**：响应时间、吞吐量、发布频率、故障率、MTTR
- **成本类**：获客成本（CAC）、运营成本、节省金额、ROI
- **团队类**：团队规模、人效、满意度评分、知识分享场次

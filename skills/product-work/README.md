# 📦 产品工作技能

帮助产品经理提升日常工作效率的 AI 技能集合。

## 🎯 技能目标

这些技能专注于产品经理的核心工作场景：
- 需求文档撰写
- 产品方案设计
- 用户研究分析
- 竞品分析
- 数据分析报告

## 📚 可用技能

### [prd-doc-writer](./prd-doc-writer/)
PRD 文档智能生成助手，帮助快速产出规范的产品需求文档。

**功能特点：**
- ✅ 结构化引导流程
- ✅ 最佳实践模板
- ✅ 自动化内容生成
- ✅ 支持迭代优化

**适用场景：**
- 快速起草 PRD 文档
- 规范化需求文档格式
- 补充完善 PRD 内容

[查看详情 →](./prd-doc-writer/)
